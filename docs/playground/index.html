What you are running

      
PEMU is a chip for the Tiny Tapeout shuttle on IHP's 130 nm process. It has two small engines, each with 64 words of program memory, that drive and read up to 16 pins. Every instruction takes exactly 1 + its delay ticks, so a program fixes the timing of a protocol down to one 20 ns clock.

      
The protocols are all software. This page runs real firmware from the project: serial, LEDs, VGA video and a music box, with the same register settings the board uses.

    

    

      
How exact is it?

      
The simulator here is a JavaScript copy of the project's Python reference model. A test runs the two side by side on random programs and random host traffic and compares every register on every clock. The Python model is in turn compared with the chip's Verilog clock by clock, and with an FPGA build tick by tick.

      
clock 50 MHz · 2 engines × 64 instructions · 4-word FIFOs · 128-word packet RAM with DMA · CRC unit · 8 bidirectional pins, 7 outputs, 5 inputs

    

    

      
Writing programs

      
.side_set n lets every instruction also drive n pins. [d] adds d ticks of delay. .wrap_target and .wrap loop at no cost. wait stalls until a pin, an edge or a flag; skip cancels the next instruction but keeps its timing. The full instruction set is in docs/isa.md.
